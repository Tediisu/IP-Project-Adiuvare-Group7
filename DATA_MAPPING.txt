DATA MAPPING TABLE
==================

Instructions:
  Create a Data Mapping table from ONE of your integrations.
  Columns: Source field/Value | Target field | Rule | Notes

Integration chosen:
  Frontend "Add / Edit Item" form (React, ItemFormModal.tsx)
    -> Scheduling Planner API (FastAPI)  POST /api/items  and  PUT /api/items/{id}
  Source: form state in frontend/src/components/dashboard/ItemFormModal.tsx
  Target: ScheduleItemCreate / ScheduleItem in backend/app/schemas.py


+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Source field/Value            | Target field | Rule                                          | Notes                                                    |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Title input                   | title        | Trim whitespace. Required, 1-200 characters.  | Empty title is rejected by the API (422).                |
| (e.g. "  Calculus I ")        | "Calculus I" |                                               |                                                          |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Color tag picker              | color        | Pass as-is. Must match ^#[0-9a-fA-F]{6}$.     | Defaults to the first tag (#eb5e28). Choices come from   |
| (e.g. "#4285f4")              |              |                                               | COLOR_TAGS in lib/schedule.ts.                           |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Day chips (selected days)     | days         | Array of "Mon".."Sun". At least 1 required.   | The form blocks saving with "Pick at least one day."     |
| (e.g. Mon, Wed)               | ["Mon","Wed"]|                                               | before the request is sent.                              |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Start time picker             | start_time   | Convert minutes since midnight to "HH:MM"     | Parsed by the API as a Python time value.                |
| (e.g. 7:30 AM)                | ("07:30")    | (24-hour) using fromMinutes().                |                                                          |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| End time picker               | end_time     | Convert to "HH:MM" (24-hour). Must be later   | API returns "end time must be after start time" if not.  |
| (e.g. 9:00 AM)                | ("09:00")    | than start_time.                              | Defaults to start + 60 minutes for new items.            |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Lecture / Lab checkboxes      | types        | Array of "lecture" and/or "lab".              | Optional; empty array [] if neither is checked.          |
| (e.g. Lecture checked)        | (["lecture"])|                                               |                                                          |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Instructor input              | instructor   | Trim whitespace. Blank becomes null.          | Optional.                                                |
| (e.g. "Dr. Santos")           |              |                                               |                                                          |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| Location input                | location     | Trim whitespace. Blank becomes null.          | Optional.                                                |
| (e.g. "Room 204")             |              |                                               |                                                          |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+
| (none; generated by server)   | id           | Auto-incremented integer on POST. Taken from  | Not sent by the form. Returned in the response. Items    |
|                               |              | the URL path on PUT /api/items/{id}.          | are kept in memory and reset when the backend restarts.  |
+-------------------------------+--------------+-----------------------------------------------+----------------------------------------------------------+


Example
-------
Form input:
  Title: "  Calculus I "   Color: #4285f4   Days: Mon, Wed
  Start: 7:30 AM   End: 9:00 AM   Type: Lecture
  Instructor: "Dr. Santos"   Location: ""

Request body sent (POST /api/items):
  {
    "title": "Calculus I",
    "color": "#4285f4",
    "days": ["Mon", "Wed"],
    "start_time": "07:30",
    "end_time": "09:00",
    "types": ["lecture"],
    "instructor": "Dr. Santos",
    "location": null
  }

API response (201 Created):
  { "id": 1, "title": "Calculus I", "color": "#4285f4", "days": ["Mon", "Wed"],
    "start_time": "07:30:00", "end_time": "09:00:00", "types": ["lecture"],
    "instructor": "Dr. Santos", "location": null }
